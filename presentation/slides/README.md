## Diagrams to Create (2)

### Diagram 1: Forge Problem — Three Legacy Systems (Slide 17)

Three horizontal boxes in a row:
- **Box 1:** "Budget Creation" — subtitle: "Manual entry, export to Excel, no comparison"
- **Box 2:** "Staffing / Deployment" — subtitle: "Duplicate projects, phone calls to sort versions"
- **Box 3:** "Monitoring & Reporting" — subtitle: "Backward-looking only, 30-day lag on issues"

Below all three: a label: "10+ years of business logic each · No integration between systems"

**Style:** Clean, muted colors. These are the "before" — they should feel heavy/constrained.

### Diagram 2: Forge Architecture — Experience Layer (Slide 19)

Vertical stack:
- **Top:** Forge UI (clean, modern) — label: "Forge — Unified Interface"
- **Middle:** Wide bar — label: "AI + Experience Layer" with sub-labels: "Flex Felix AI Agent · Smart Defaults · Predictive Monitoring · Budget Comparison"
- **Bottom:** Three boxes (same as Diagram 1 but smaller): "Budget Creation," "Staffing / Deployment," "Monitoring & Reporting"
- **Arrows** flowing upward from legacy systems through the experience layer to the UI

**Style:** The experience layer should feel like the connective tissue — a different color or treatment from both the legacy systems below and the Forge UI above. The message is: "we didn't replace, we elevated."

## Design Direction for the Deck

- Clean, modern, minimal. Let the work speak.
- Dark background for section transitions / title cards (slides 1, 6, 16, 26)
- Light background for content slides
- Typography-forward. Large headlines, generous whitespace.
- Images should be LARGE and contextual — real products in real environments
- No decorative elements. No icons for the sake of icons.
- Color palette: neutral base (white/near-black) with a warm accent (the orange/coral from the Forge UI would work as a through-line)
- **Tone:** Confident, warm, direct. This deck should feel like Pia — not a template.
